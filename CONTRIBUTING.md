# Contributing

## Build and test

- Android: `android/gradlew test`
- Windows: `dotnet test windows/KeyRelay.slnx`

## Commit format

```
type(scope): description
```

Types: `feat`, `fix`, `refactor`, `perf`, `docs`, `test`, `chore`, `ci`, `build`, `revert`.

## Pull requests

Fill in the pull request template (`.github/PULL_REQUEST_TEMPLATE.md`): summary, devices tested, and whether `CHANGELOG.md` was updated.
